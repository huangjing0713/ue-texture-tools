## 目标

做一套「美术贴图进引擎前」的自动化工具链，分两步：

1. **texture-naming-linter** —— 贴图命名规范校验（发现问题）
2. **texture-import-materializer** —— 贴图批量导入 UE + 自动建材质实例（解决问题）

一条完整的管线叙事：先发现问题（A），再做工具解决（B）。
